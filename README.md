## 📖 About

🔹 **RimWorld — RimSaves** is a powerful tool built to help you manage, organize, and restore RimWorld save files with advanced backup and versioning capabilities. Never lose a colony to corruption or accidents — RimSaves automatically creates versioned backups on a configurable schedule.

🔸 Whether you're a seasoned professional or just getting started, **RimWorld — RimSaves** delivers a clean, intuitive experience packed with everything you need — right out of the box. Join thousands of users who've already streamlined their RimWorld modding workflow. Download now and get started in minutes. 🚀

## 🚀 Features

| Feature | Description |
|---------|-------------|
| Auto Backup | Automatic save backups on configurable time intervals |
| Save Versioning | Keep multiple versions of the same save for time-travel restoration |
| Cloud Optional | Optional backup to network drive or cloud-synced folder |
| Easy Restore | Browse and restore any previous save version from the in-game menu |
